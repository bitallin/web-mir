# ADR-001: Web-first 2D / 伪等距，Phaser 4

- 状态：Accepted
- 日期：2026-11-24
- 关联：架构文档 0.2、3.1、7

## 决策

游戏采用浏览器原生 2D 斜 45° / 伪等距表现，渲染使用 Phaser 4 + TypeScript。

## 理由

浏览器即开即玩是产品形态；Phaser 适合 2D tile 地图、精灵、动画、输入和摄像机，
不引入 3D 引擎和下载客户端。

## 影响

- 客户端需要脚底锚点、Y-sort、遮挡层和统一资源规范。
- 服务端逻辑坐标不能依赖屏幕像素。
- 不使用 Emoji、色块或纯 CSS 形状冒充最终美术。

## 调整条件

只有在明确的产品需求证明 2D 表现无法满足，并且有资源与团队能力承担 3D
管线时，才通过新 ADR 评估更换。
