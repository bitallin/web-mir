# ADR-032：装备成长线、稀有品质与背包对比

- 状态：Accepted
- 日期：2026-11-26
- 阶段：Alpha 0.2 S4（切片 A）
- 关联：ADR-020（资产事务）、ADR-022（内容发布）、ADR-026（商店与经济）、
  ADR-029（动画资源与 manifest）、EL-004（内容 checksum）、EL-019/021
  （测试与世界内容耦合）、TD-CLI-13（正式美术）、`docs/PROJECT_ROADMAP.md` §3

## 1. 背景

Alpha 0.2 的验收要求“1–15 级内容完整：玩家不会在 5 分钟后无怪可打、无装备
可追”。S1–S3 已让玩家能买卖、有职业技能、怪物危险、死亡有代价，但装备仍只有
3 把初始武器与 2 件护甲：击杀几乎不产出装备，玩家在 30 分钟循环里没有“下一件
装备”的目标。

## 2. 问题

1. 装备获取路径单薄：除初始武器外只有皮甲低概率掉落，没有分层追求。
2. 掉落缺乏可感知的价值差异：所有物品外观与信息相同，稀有掉落没有惊喜。
3. 玩家无法判断背包里的装备比身上强多少，需要心算属性。
4. 物品数量上升后（材料 + 装备 + 药水）背包没有整理手段。
5. 内容一旦增加装备，可能出现“没有任何获取途径”的死内容，运营无法从校验
   中发现。

## 3. 备选方案

1. **扩展装备槽（头盔/项链/戒指）。** 需要数据库约束、客户端布局、掉落与
   平衡全面调整，超出本切片；且 S4 的计划只要求武器与防具可掉落。
2. **只增加数值装备，不引入品质。** 有装备可追，但掉落反馈仍平淡，也无法
   区分普通与稀有掉落；产品原则要求“掉落的惊喜”。
3. **随机词条/附魔。** 需要随机生成、存档结构与平衡验证，属于 Alpha 0.3。
4. **内容扩展 + 可选品质字段 + 客户端对比与整理（采纳）。** 复用现有资产事务
   与内容发布链路，改动面小且可独立验收。

## 4. 决策

1. `ItemContent.quality?: 'common' | 'rare'`，缺省为 `common`。字段为可选且不写
   默认值，历史 Release 的 checksum 不变（EL-004）；`ItemView.quality` 同样
   可选，服务端从内容读取后下发。
2. 品质不参与任何战斗计算，只影响展示与内容设计；装备数值仍显式写在内容里，
   便于运营审查与平衡。
3. 新增 12 件装备：每职业 3/5/7 级武器（7 级稀有），以及 4/6/7 级护甲
   （7 级“狼王皮甲”稀有）；连同初始装备共 17 件。
4. 掉落按怪物等级分配：森林狼产出 3 级武器、毒牙蜘蛛与石甲守卫产出 4–5 级
   护甲与 5 级武器、白狼王产出稀有武器与狼王皮甲。3 级武器与锁子甲同时上架
   商店，形成金币消耗端与等级目标。
5. 内容校验新增两条规则：
   - 错误：非装备物品不得设置 `quality`（新字段，历史数据不会触发）。
   - 警告：装备必须能获得（掉落表、出售价或初始装备）。使用警告而非错误：
     历史 Release 在没有商店价格前就已存在，错误级规则会让活动内容在
     `ContentStore` 加载时失败（EL-021 同类）。
6. 背包对比与整理是客户端纯函数（`apps/game-web/src/lib/inventoryView.ts`），
   只改变显示顺序与提示；服务端 `slotIndex`、装备槽与属性快照仍是权威，
   不新增协议命令。
7. 商店面板与背包面板互斥打开：商店为居中大面板，会覆盖背包的控制区域，
   同时展开会让背包按钮不可点击。

## 5. 影响

- 内容工作台可直接编辑 `quality` 与价格；发布前校验提示无法获得的装备。
- 新内容 Release `2026.11.26.5`（checksum `a0805598…`）发布并激活；旧 Release
  保持有效。
- 客户端背包：稀有品金色描边与“稀有”标签、对比行（“装备后/较当前 ±属性”）、
  整理按钮；整理只影响显示。
- 商店目录包含新上架装备，按职业过滤；等级不足时按钮禁用并提示。
- 未处理：装备槽扩展、物品图标（TD-CLI-13）、丢弃物品、装备耐久与修理。
- 已知体验问题：商店面板仍会覆盖顶部 HUD 开关，需要先关闭商店再打开背包
  （TD-CLI-14）。

## 6. 验收

- 单元：品质缺省、对比增量与描述、整理顺序、新校验规则。
- E2E：新角色购买布衣 → 背包显示品质与“装备后 防御 +2” → 整理后装备在前 →
  装备后服务端属性防御 8 → 10。
- 内容：`2026.11.26.5` 激活后新 Room 使用新目录；开发栈实测商店出现 3 级武器、
  锁子甲与皮甲，背包显示品质与对比。
- 回归：全量单元/集成 433、浏览器 E2E 32/32、构建与 lint/typecheck 通过。
