# Alpha 0.2 S2 任务 2：三职业等级技能与状态效果

- 日期：2026-11-26
- 范围：S2 剩余技能差异（DoT、护盾、等级解锁）；不含三套职业外观与动作
- 关联：`docs/ADR/ADR-028-damage-over-time-and-shield-effects.md`、
  `docs/ALPHA_02_EXECUTION_PLAN.md` §4、`docs/PROJECT_STATUS.md`

## 1. 目标

让三个职业在 1/5/10 级获得不同的操作方式，而不只是数值表不同：

- 道士：治疗 + 持续伤害（毒符），定位为持续与辅助。
- 战士：近战爆发 + 护盾减伤，定位为正面承伤。
- 法师：远程爆发 + 护盾，定位为高消耗高爆发。

同时修复一个真实的内容顺序问题：Content Release 存在 PostgreSQL `jsonb` 中，
键会被重排，技能栏顺序会随 Release 变化。

## 2. 实际改动

### 2.1 契约

- `skillEffectSchema` 新增 `dot`、`shield` 两种白名单效果。
- `hit` 事件新增可选 `skillId`、`absorbed`、`periodic`；新增 `shield` 事件。
- `combat.profile` 新增可选 `shield`，重连/升级后可以恢复护盾数值。

### 2.2 内容

- 每职业 3 个技能，等级 1/5/10、快捷键 1/2/3：

| 职业 | 1 级             | 5 级                      | 10 级           |
| ---- | ---------------- | ------------------------- | --------------- |
| 战士 | 重击 160%+4      | 铁布衫 40(+6/级) 护盾 8s  | 破军斩 220%+10  |
| 法师 | 火球术 140%+6    | 魔法盾 50(+8/级) 护盾 10s | 陨石术 260%+14  |
| 道士 | 治愈术 30(+4/级) | 施毒术 60%+2 / 秒 ×6s     | 灵魂火符 190%+8 |

- 内容校验：`dot` 只能敌方、`shield` 只能自身；持续时长不能短于跳伤间隔；
  冷却短于持续时间会给 warning。

### 2.3 领域

- `CombatWorld` 增加 `dots` 与 `shield` 运行时状态。
- DoT 每秒跳伤，伤害在施法时确定，不掷命中/暴击、不消耗 RNG；以技能 ID 刷新，
  目标死亡/重生清除，击杀归属施法者。
- 护盾先吸收伤害再扣 HP；耗尽、到期、死亡都会清除并广播 `shield` 事件。
- `skillsForClass` 按解锁等级 + 快捷键排序，消除 `jsonb` 键序影响。

### 2.4 服务端与客户端

- Room 的 `shield` 事件按施法者/目标 AOI 投递；DoT 击杀沿用击杀奖励事务。
- 客户端：护盾数值显示在顶部状态与角色面板；战斗日志/浮字区分持续伤害与
  护盾吸收；技能栏顺序稳定。

## 4. 开发中发现并修复的问题

1. **技能栏顺序不稳定**：E2E 断言 `skill-2` 时发现战士显示的是重击而不是铁布衫。
   根因是 Release payload 存为 `jsonb`，PostgreSQL 会按长度/字节重排对象键。
   修复为 `skillsForClass` 显式按等级/快捷键排序，并在单测中断言顺序。
   → 新增 EL-018。
2. **DoT 跳伤与 RNG**：如果每跳都掷命中/暴击，会改变后续攻击的 RNG 序列，
   回放与确定性测试失效。改为施法时固定每跳伤害、跳伤不消耗 RNG。
