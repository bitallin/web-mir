## 1. 目标

S4-A 让 1–7 级有装备可追，但内容上限仍停在 6 级怪与 7 级装备：10 级技能
解锁后没有对应怪物，玩家升级只为数值。本切片补齐路线图中的第三片野外区域
（残垣废墟），把有效成长线延伸到 8–10 级，并给高等级角色新的金币消耗端。

## 2. 交付内容

### 2.1 新地图：残垣废墟（`ruined_fields`）

- 48×36 野外地图，`kind: wilds` → 编译为开放 PvP；三处残垣庭院、石地/土路/
  草地/水池，沿用现有 8 个占位 tile，未改动资源 manifest 版本。
- Tiled 源图 `content/maps/ruined_fields.tmj`；`pnpm maps:compile` 生成
  `content/maps/compiled/ruined_fields.json`（checksum `57799b04…`）。
- 出生点 `(4,18)` 标记为复活点；西侧入口是一片 7 格内无刷点的安全空地，
  最近怪物在 7 格外（骷髅 `aggro 5`），低等级角色可以先观察再决定是否深入。
- 29 个刷点：16 骷髅武士、12 腐化术士、1 废墟石像鬼；与主城/荒野一致控制在
  20–40 刷点范围。
- 双向传送门：主城西北角 `(3,2)` → 废墟 `(4,18)`；废墟 `(3,18)` → 主城 `(4,2)`。
  入口放在主城而不是荒野：荒野的决斗点 `(12,10)/(13,10)` 与多条既有 E2E 寻路
  都会经过中北部，任何放在那里的传送门都会把玩家意外传送走（本轮实测复现）。

## 4. 顺带修复与测试稳定性

1. **economy 与 autoAttack 共用 `wilds_slime_1`**：两个用例并行时先击杀的一方
   拿走奖励，另一方永远等不到掉落。economy 改用独立刷点 `wilds_slime_11`
   （EL-019 同类，TD-QA-11 的具体缓解）。
2. **classes 攻击动画用例依赖怪物 `attack` 状态**：目标被其他用例引走时会
   长时间处于 `return`，与玩家是否进入射程无关。改为等待自身角色到达目标格，
   再触发攻击并断言动画片段。
3. **传送门位置的口径**：新传送门会把玩家从原路径上“吸走”，既有用例的寻路
   与决斗点都受影响。城市入口既避开全部既有路径，也让新区域更易被发现。
