# Alpha 0.2 S3 切片 1：怪物威胁与扑击预警

- 日期：2026-11-26
- 范围：S3 第一切片——怪物生态扩充（远程/重甲/精英）与服务端权威的攻击前摇
- 关联：`docs/ADR/ADR-030-monster-windup-and-telegraph.md`、
  `docs/ALPHA_02_EXECUTION_PLAN.md` §4、`docs/PROJECT_STATUS.md`

## 1. 目标

让“野外有危险”成为可感知的玩法，而不是数值上更容易掉血：

- 新增远程、慢速重甲与精英三类怪物，行为差异不靠新增枚举；
- 精英的扑击有可见预警，玩家可以通过走位躲开；
- 命中与躲避都由服务端裁定，保持确定性回放与反作弊边界。

## 2. 实际改动

### 2.1 契约（加法）

- `monsterContentSchema` 增加可选 `windupMs`（0–5s）与
  `windupRadiusTiles`（0–6）；不设默认值，旧 Release checksum 不变（EL-004）。
- `combat.event` 新增 `telegraph`：攻击者、目标、落点整数子格坐标、闪避半径
  与落地剩余毫秒。`PROTOCOL_VERSION` 不变（同版本前后端加法发布）。

### 2.2 内容与校验

- 基线新增 3 类怪物与 3 种材料：
  - 毒牙蜘蛛（Lv4，远程 3.2 格，生命 60，缓慢移动）；
  - 石甲守卫（Lv5，生命 230、防御 10、移速 900）；
  - 白狼王（Lv6 精英，生命 320、攻击 18、扑击前摇 900ms、闪避半径 1.5 格）。
- 新增掉落表：蛛腿（售 10）、石甲核心（售 22）、狼王毛皮（售 45）；精英经验
  80、金币 25–40，并有机会掉落皮甲。
- 校验：设置了闪避半径却没有前摇 → error；前摇不短于攻击间隔 → warning。
- `starter_wilds` 新增 6 个刷点（精英 1、蜘蛛 3、守卫 2），总数 30 → 36，仍在
  阶段 8 的 20–40 目标内；重新编译地图。

### 2.3 领域

- `CombatWorld` 增加前摇运行时：带 `windupMs` 的怪物在攻击冷却到期时冻结
  位置、提交落点并发出 `telegraph`；落地 tick 才掷命中/暴击/伤害。
- 目标在落地时已死亡/断线 → 攻击作废；离开半径 → `miss`；否则照常结算。
- 怪物死亡、重生清除未落地攻击；前摇期间不追击、不重选目标。
- 前摇本身不消耗 RNG，保证同一随机种子下事件序列稳定。

### 2.4 服务端

- `broadcastCombatEvent` 把 `telegraph` 与 `attack`/`hit`/`miss` 归为同一
  路由组：只投递给能看见攻击者或目标的会话。
- 新增真实 PostgreSQL + Colyseus 集成测试：注入精英刷点，断言预警先于伤害、
  落点/半径/延迟正确、无人移动时命中由服务器结算。

### 2.5 客户端

- 预警圈：红色范围椭圆 + 内部填充在前摇时长内展开；落地后 120ms 或怪物死亡
  时清除。
- 目标是自己时写战斗日志“蓄势扑击，快离开红圈”，并播放新增的低音预警音效。
- 新怪物占位造型：白狼（浅色狼形）、蜘蛛（多足圆身）、石甲守卫（块状重甲）。
- 仅开发环境暴露 `activeTelegraphs()`，供 E2E 证明预警已渲染。
