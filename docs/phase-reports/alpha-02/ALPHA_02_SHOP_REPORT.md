## 1. 结论

主城杂货商切片完成：玩家可以用初始金币购买药水/护甲，把打怪掉落的材料与多余
装备卖回商人；金币、背包与账本在同一数据库事务中变化；重复指令不重复结算；
远离商人、金币不足、背包满、不可售物品均由服务端拒绝且无副作用。

真实浏览器 E2E 走通了“新角色 50 金币 → 走近商人 → 买药 → 卖回 → 离开重进后
数据仍在”。本轮同时修复了一个由并发商店测试暴露的资产命令死锁，并移除了玩家
界面遗留的“阶段 6”内部标签。

未完成项必须明确：50 人 × 10 分钟容量回归本轮未执行；远端 CI 未执行；开发栈
84–87 需要重启后才会加载新服务端代码（`pnpm dev` 不热重载后端）。

## 2. 交付内容

### 2.1 内容与数据

- `ItemContent` 增加可选 `buyPrice` / `sellPrice`；使用 `.optional()` 而不是
  默认值，历史 Release 的 checksum 不变（EL-004）。
- 基线价格：金创药 15/5、魔法药 18/6、布衣 40/12、皮甲 120/35、材料 4/8。
  初始职业武器为绑定物品（无可售价格），避免新玩家卖掉唯一武器后无法恢复。
- 内容校验新增“收购价必须低于出售价”，阻断买卖套利。
- `starter_town` NPC 增加 `role`（`merchant` / `guard`）；编译产物重新生成。
- 地图编译拒绝协议无法寻址的 `npcId`，避免一个错误内容在玩家加入时触发
  catalog 校验异常。
- 新角色创建时在同一事务写入 50 金币钱包与 `starter_gold` 账本记录。

### 2.2 契约与协议

- `shop.buy` / `shop.sell`（Client → Server）与 `shop.catalog`（Server → Client）。
- `assetCommandKind` 增加 `shop_buy` / `shop_sell`。
- 新拒绝码：`SHOP_UNAVAILABLE`、`INSUFFICIENT_GOLD`、`CANNOT_SELL`、
  `NOT_SOLD_HERE`、`INVALID_QUANTITY`。
- 目录只包含展示所需字段；价格由服务端按 Room 固定内容重算，客户端不提交
  价格或金币结果。

### 2.3 应用与服务端

- `AssetService.buy`：角色行锁 → 幂等命令 → 条件扣款 → 账本 → 入包；背包满
  整体回滚。
- `AssetService.sell`：角色行锁 → 幂等命令 → 校验归属/可售 → 扣减或删除 →
  钱包与账本。
- Room：`CommandGuard` 统一校验会话/协议/序号/限频/幂等；校验与 `merchant`
  NPC 距离 ≤ 3 格；加入世界后下发本图商店目录（按职业过滤可购商品）。
- 资产命令统一改为先锁角色行再写幂等命令，消除外键共享锁与 `FOR UPDATE`
  的死锁（EL-012）。

### 2.4 客户端

- 靠近商人时 HUD 出现“杂货商”入口；商店面板居中，购买/出售两个页签。
- 购买页显示价格、属性/回复、等级需求；金币不足时按钮禁用。
- 出售页显示可售物品、单价、数量，支持卖 1 与全部。
- 金币与背包在 `asset.result` 后刷新；离开范围自动关闭商店。
- 移除玩家可见的“阶段 6”标签。

## 4. 发现的问题与处理

1. **并发购买死锁（新发现，已修复）**：幂等命令插入的外键先取角色行共享锁，
   随后 `FOR UPDATE` 申请排他锁，两笔并发交易互相等待。统一改为先锁角色行，
   并增加并发购买测试（只有一笔成功、余额为 5、另一笔 `INSUFFICIENT_GOLD`）。
2. **E2E 重进假设错误（测试问题，已修复）**：离开世界后客户端停留在“已断开”
   界面，不会回到登录页；测试改为点击“返回角色”再进入世界。
3. **玩家可见内部标签（已修复）**：移除“阶段 6”。
4. **新手武器陷阱（自查发现，已修复）**：初始职业武器原本可卖 30 金币，但商人
   不出售武器，卖掉后无法恢复。改为绑定物品（无 `sellPrice`）。

5. **场景 NPC 没有点击交互（2026-11-26 用户实测）**：此前只有靠近后的 HUD
   按钮；点击世界里的杂货商标记只会寻路。已增加 NPC 命中检测、`interactNpc`
   与“距离不足”提示；商店 E2E 改为直接点击 NPC。
6. **发布可选字段 Release 返回 500（2026-11-26 实际发布发现）**：diff 把旧版本
   缺失的 `buyPrice`/`mpRegenPerSecond` 作为 `undefined` 传给 `canonicalJson`
   并抛错。已增加 `jsonForDiff` 与“缺失 vs 存在”回归测试；发布/激活成功。
