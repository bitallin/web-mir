# Alpha 0.3 S3-M：八方向移动与键盘操作报告

- 日期：2026-11-27
- 切片：Alpha 0.3 S3-M「八方向移动：斜向寻路/阻挡、WASD 短步、空格停止」
- ADR：`docs/ADR/ADR-043-eight-way-movement-and-keyboard-controls.md`
- 关联：ADR-016（四方向移动基线，已被本切片补充/替代）

## 1. 目标

关闭两项长期技术债：TD-CLI-18（四方向移动，斜向目标走 L 线）与 TD-CLI-07
（无键盘移动、无停止指令）。玩家应当可以用鼠标点击斜向目标直接斜走，也可以
用 WASD/方向键八方向移动，并用空格明确停止。移动仍然完全由服务端寻路与位置
裁定，客户端只提交意图。

## 2. 交付内容

### 2.1 寻路与阻挡

- `findPath` 改为八邻域 BFS，邻居顺序固定并优先展开离目标更近的方向，避免
  同长度路径绕行一行。
- 斜向步只有在两个正交邻格都可走时才合法（禁止切角）：
  `(x,y) -> (x+dx,y+dy)` 要求 `(x+dx,y)` 与 `(x,y+dy)` 可走。
- `game-simulation` 新增 `isStepAllowed`，`WorldSimulation.setPath` 校验路径
  每一步的相邻性与斜向阻挡，非寻路来源的路径也不能注入非法对角步。
- 测试替身 `game-domain/testSupport.bfsPath` 同步为八方向，注入路径与生产一致。

### 2.2 速度与步进

- 每段距离使用欧氏长度 `round(hypot(dx, dy))`；对角步约 1414 单位，按
  4000 单位/秒约 353ms，与直线步的 250ms 成 √2 比例，斜向不产生速度优势。
- 位置继续使用整数子格单位，单步预算不足时按比例取整推进；服务端确定性、
  可回放。移动信用跨段累积，长期平均速度仍为 4 格/秒。
- 怪物 `advanceMonster` 使用同一欧氏步进规则。

### 2.3 重寻路与预测

- 取消“格内先回当前格中心”的轴对齐回退：新路径直接从当前位置走向第一个格
  中心。八方向下该线段只经过当前格、目标格与两个正交邻格，均已被阻挡规则
  保证可走。
- 客户端 `buildPredictionWaypoints` 与服务端 `setPath` 同步：丢弃服务器起步格
  后直接以格中心为路点；空路径仍走回当前格中心后停止。
- 客户端预测距离改为欧氏距离，与服务端步进一致。

### 2.4 朝向

- `FACING` 保留既有 0–3（n/e/s/w），追加 `northEast=4`、`southEast=5`、
  `southWest=6`、`northWest=7`；旧持久化数据与旧客户端不受影响。
- 新增 `facingFromDelta` 纯函数；移动时按位移方向设置八方向朝向。
- 四方向角色贴图在表现层用 `facing % 4` 映射（NE→N、SE→E、SW→S、NW→W），
  不需要美术资源扩容。
- `characterViewSchema` 与 Game Server 视图校验上限从 3 改为 7；无数据库迁移。

### 2.5 键盘与停止

- `WorldScene` 监听 WASD/方向键：按住时每走完一格再提交下一格 `move.to`；
  两键组合斜走，相反键抵消；新按键立即打断点击路径。
- 输入框/文本域/下拉框聚焦时忽略移动键；已聚焦的按钮/链接保留空格的原生
  激活行为。
- 新增 `move.stop` 客户端命令（`protocolVersion` + `commandId` +
  `clientSequence`），复用统一命令门禁：协议、重复 id、序号、限频。
- 服务端收到后清空权威路径、停止自动攻击与任务导航，返回空 `path` 的
  `command.ack`；空格键在客户端发送该命令并清空本地预测。

## 3. 验证

### 3.1 单元与集成

- 新增/更新：八方向 BFS（直线、对角、绕墙、拒绝切角、确定性）、
  `isStepAllowed`、欧氏步进与斜向朝向、客户端预测对角路径、键盘方向合成与
  斜向阻挡、`FACING`/`facingFromDelta`、`move.stop` 契约。
- 真实 Game Server 集成：对角 `move.to` 路径包含对角步并在两轴精确到达；
  `move.stop` 后位置保持不变。
- 全量 `pnpm test`：**600 个测试通过**（新增 13 条）。

### 3.2 浏览器 E2E

- `tests/e2e/movement.spec.ts` 新增：按住 D+S 斜向移动；空格停止后位置稳定；
  聊天输入框聚焦时方向键不会移动角色。
- 自动攻击平滑度用例增加两个前置条件：先走到目标附近再锁定（巡游怪物可能越过
  AOI 格边界），并等待权威路径真正开始移动后再采样。
- 平滑度判据改为“服务端位置未变、但客户端预测位置前进”的采样数：只跟随快照
  的客户端不会产生这种更新，而路径预测会；该判据不依赖软件渲染帧率
  （此前的速率阈值在 16–25 FPS 下无法区分 20Hz 快照）。
- 为诊断新增只读调试钩子 `selfServerPosition`（本地玩家最近一次权威快照位置），
  不参与游戏逻辑。

### 3.3 最终结果

- 格式 / lint / 类型 / 构建：通过。
- 单元/集成：83 文件、**600 测试**通过。
- 全量浏览器 E2E（串行，隔离库与端口）：**49/49 通过**（10.8 分钟）。
- 50 人 × 2 分钟容量 sanity（开发栈 84，新代码）：50/50 加入、接受率 98.9%、
  194 击杀、0 资产失败；tick p50 1.48ms / p95 **3.72ms** / p99 5.06ms /
  max 6.57ms，资产事务 p95 62.03ms；证据
  `docs/phase-reports/alpha-03/eight-way/load-50p2a.json`。
- 8584 实测：新角色从 (10,10) 按住 D+S 后预测位置 (12641, 11641)、权威位置
  (12500, 11500)，两轴同时前进；空格停止后权威位置 (12923, 12923) 保持不变，
  客户端预测收敛误差 1.79 单位。证据
  `docs/phase-reports/alpha-03/eight-way/dev-eight-way-8584.png`、
  `dev-eight-way-8584.json`。
- 开发栈 84–87 已重启到本切片代码，4 个服务健康 200，内容 `2026.11.27.7`
  继续有效（本轮无内容变更）。

## 4. 未验证 / 已知限制

- 正式美术仍只有四方向帧；斜向走动使用最近基本方向，八方向资源留待
  TD-CLI-13。
- 狭窄单格走廊的拐角仍需要一个正交步（禁止切角），这是碰撞规则。
- 键盘按键不可配置，手柄未支持。
- 远端 CI 仍待确认（本环境无 gh）。

## 5. 债务影响

- 关闭 TD-CLI-07、TD-CLI-18。
- 不新增 P0/P1/P2；无数据库迁移、无内容发布。
- `move.stop` 为加法协议；旧客户端不发送该命令，行为不变。
