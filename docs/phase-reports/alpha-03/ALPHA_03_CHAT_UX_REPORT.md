# Alpha 0.3 体验修复：聊天连续性与回复操作

- 日期：2026-11-28
- 范围：Alpha 0.3 私聊体验修复（客户端）
- 关联：ADR-046、TD-CLI-04、TD-CLI-17
- 证据：`docs/phase-reports/alpha-03/friends/e2e-whisper.png`

## 1. 试玩反馈

1. 换地图后，之前所有聊天频道的记录都消失了。
2. B 收到 A 的私聊后，点击聊天框里 A 的名字应直接开始回复 A。
3. 参考同类 MMORPG 的统一做法，完善聊天体验。

## 2. 根因

`useWorldSession.handleTransfer` 在过图时把会话状态当成“地图状态”整体重置：
`messages`、`systemMessages`、`friends` 与 `party` 都被清空。聊天记录本身只
存在客户端内存，因此被这次重置删除；好友快照被清空还会让“正在私聊”的目标
被自动清除。Phaser 场景同时被销毁重建，这是 TD-CLI-04 的另一半，但与本轮
反馈无关，继续保留为债务。

## 3. 实际改动（仅客户端）

### 3.1 对话状态跨图保留

- 过图不再清空 `messages`、`systemMessages`、`friends` 与 `party`；地图实体、
  战斗状态、任务快照与商店目录仍按地图重置。
- 聊天记录上限仍为 120 条、系统日志 60 条；跨多次过图也不会无限增长。
- 私聊目标、发言频道与日志筛选在过图后保持；服务端重新下发好友/队伍快照后
  在线状态自动校正。

### 3.2 点击名字直接回复

- 日志里来自**在线好友**的玩家名渲染为按钮（自己除外），地图、队伍与私聊
  消息都适用。
- 点击后：私聊目标切换到该玩家、发言频道切到私聊、日志筛选切到私聊，并聚焦
  输入框；私聊回复不再需要重新打开好友面板。
- 非好友或离线玩家保持普通文本，避免出现点了却被服务器拒绝的操作；这与
  当前“仅好友可私聊”的隐私模型一致（ADR-046）。

### 3.3 常见聊天习惯

- **未读提示**：当私聊被当前筛选或收起的聊天面板隐藏时，「私聊」标签显示
  一个紫色圆点；切到「全部 / 私聊」或展开后清除。
- **自动跟随**：新消息到达时滚动到底部；玩家主动向上翻看历史后暂停跟随，
  不会把阅读位置拉走。
- **输入历史**：输入框支持 `↑` / `↓` 召回最近 20 条已发送内容，连续重复
  不重复记录。
- **结束私聊**：发言选择器旁的 `×` 清除目标并回到附近频道，筛选同步回到
  「全部」。
- 发送成功后输入框清空、焦点保留在输入框，便于连续对话。
