# Alpha 0.3 S3-C 报告：十步主线任务链与废墟斥候

- 日期：2026-11-27
- 范围：主线任务链从 3 步扩展到 10 步、废墟野外发布者、任务面板按状态分组、
  引导提示优先主线
- ADR：沿用 ADR-034（内容驱动任务）与 ADR-038（每日任务）
- 内容：`2026.11.27.4`（checksum `5e22537c…`，新增 7、变更 1）
- 证据目录：`docs/phase-reports/alpha-03/quest-chain/`（浏览器截图、内容校验与
  激活快照）

## 1. 目标与产品判断

S3-A/S3-B 交付了每日任务与一键流程，但主线只有 3 步、在 5 级结束。新玩家
在 5–12 级之间没有目标链，只能重复刷怪；10 级之后的废墟与首领缺少叙事入口。

1. 更愿意再玩 30 分钟：是——10 步链贯穿三张地图与全部怪物，配合一键流程
   形成连续的 1–12 级目标。
2. 更愿意明天回来：是——主线终点是每日可重复的世界首领，日常与主线叠加。
3. 更愿意和别人一起玩：是——最后一步要求击败灰烬魔像，提供组队理由；前九步
   仍可单人完成，不强制社交。

任务种类仍只有击杀目标。收集/对话/到达目标会引入物品扣除或事件进度，属于
独立切片；本切片先把已经存在的击杀玩法组织成完整成长线。

### 2.2 废墟斥候（新 NPC）

- 契约 `MAP_NPC_ROLES` 增加 `scout`；地图编译器改为直接校验契约枚举，避免
  角色列表与运行时 schema 各写一份。
- `ruined_fields` 的 `npc_points` 新增 `ruins_scout`「废墟斥候」@ `(7,20)`：
  距入口 `(4,18)` 三格、远离刷点与既有 E2E 路径，可见且不阻挡移动。
- 任务视图的发布者名字继续从全部编译地图解析；玩家在主城也能看到
  「残垣废墟 · 废墟斥候」。
- 编译地图 checksum 更新；地图新鲜度测试覆盖新 NPC 与非法角色拒绝。

### 2.3 任务面板分组

- 新增客户端纯函数 `groupQuestsByStatus`：按「可交付 → 进行中 → 可接取 →
  尚未解锁 → 已领取」分组，隐藏空分组，组内保留服务器顺序。
- 面板标题显示每组的任务数量，分组标题滚动时吸顶；任务量从 5 条增至 12 条后，
  可操作任务不再被锁定的后续步骤淹没。
- 新增 `nextAvailableQuest`：引导提示优先一次性主线，再按等级；避免新玩家
  先被每日任务带走。

- 内容校验继续覆盖：发布 NPC 必须存在于编译地图、目标怪物必须有刷点、奖励

## 4. 遇到的问题及解决方法

1. **校验发现斥候不在任何地图**：地图 NPC 属于编译产物与代码，不属于内容
   Release；运行中的 Control API 仍持有旧地图。重启开发栈后校验通过。
   运营顺序应为“先发布带地图/契约的代码，再发布引用它的内容”（EL-040）。
2. **任务面板在 12 条任务时可读性下降**：按状态分组并优先可操作任务；锁定
   组保留但排在后面。
3. **引导提示先指向每日任务**：`nextAvailableQuest` 优先一次性主线，避免
   新玩家被可重复内容带离故事线。
4. **地图编译产物与 Prettier**：`pnpm maps:compile` 输出需要再跑一次 Prettier，
   否则 `format:check` 失败；编译内容本身不变。
5. **压测脚本在 teardown 挂起**：50 人 sanity 中一名 mover 走进传送门被传到
   主城，客户端 `room.leave()` 永不返回；报告已写出但进程不退出。修复为有界
   等待 5 秒并关闭仍打开的连接；10 人 smoke 与 50 人复跑均以退出码 0 结束。

## 5. 尚未解决

- 任务目标仍只有击杀；收集/对话/到达目标未做。
- 没有放弃任务、任务日志历史、NPC 头顶感叹号与队伍共享任务进度。
- 任务面板只有状态分组，没有搜索/筛选；任务继续增长时需要。
- 第 10 步依赖世界首领，单人或低峰时段可能等待刷新或与他人争夺。
- 废墟入口是开放 PvP 地图，斥候附近没有局部安全区；交付后五步时可能被其他
  玩家伏击。局部安全区是路线图中的独立能力，本切片未做。
- 自动战斗仍只用普攻（TD-CLI-19）；远程接取仍是真实旅程。
